# Documents

本目录用于记录已经开始实现的运行时模块设计说明。它和 `doc/tasks` 的职责不同：

- `doc/tasks`：开发过程 TODO、里程碑、进度追踪。
- `doc/documents`：已经落地到代码中的设计思路、模块边界、数据流和后续扩展依据。

## 当前文档

- [map](./map.md)：地图生成、地块数据、地图渲染、地图交互与寻路查询设计。

## 编写约定

只有当某个模块开始编写逻辑代码后，才在本目录新增对应设计文档。尚未实现的模块不提前写设计说明，避免文档对实现方向形成错误约束。

文档使用普通 Markdown 编写，并尽量保持 Markdoc 友好：标题层级清晰、表格和列表保持简单、避免依赖特定渲染器的语法。
