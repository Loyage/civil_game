# local_map 测试与验证计划

## 目标

小地图生成必须可复现，并且与相邻地块衔接合理。测试重点不是视觉效果，而是生成一致性、边界连续性和缓存版本安全。

## 可复现性测试

同一输入必须得到完全一致输出：

- 相同 `world_seed`
- 相同 `tile_col/tile_row`
- 相同生成配置版本

验证方式：

1. 连续生成同一个地块两次。
2. 对比 `heights`、`water_flags`、`river_flags`、`slope_values`。
3. 生成摘要 hash。
4. 两次 hash 必须一致。

## 边界连续性测试

相邻地块边界高度应保持视觉连续，但不再要求复用同一个全局采样坐标。小地图现在使用 `tile_col * sub_map_size + cell_x` / `tile_row * sub_map_size + cell_y`，优先保证小地图严格归属于对应大地图地块，避免采样到相邻地块的海洋掩码。

- A 地块右边界与 B 地块左边界高度差应在可接受范围内
- A 地块下边界与 C 地块上边界高度差应在可接受范围内
- 大地图陆地地块的小地图不应因为相邻海洋地块而大面积显示水域

验证方式：

```text
abs(east_tile.cell(sub_map_size - 1, y).height - west_neighbor.cell(0, y).height) <= allowed_delta
abs(south_tile.cell(x, sub_map_size - 1).height - north_neighbor.cell(x, 0).height) <= allowed_delta
```

## 水域一致性测试

大地图和小地图的海洋判定必须一致：

- 大地图非海洋地块的小地图 `water_flags` 不应大面积为 `1`。
- 大地图海洋地块的小地图可以显示水域主体。
- 如果小地图水域样本超过半数，大地图摘要应显示为 `ocean` 或包含 `water` 标签。

## 河流连续性测试

如果大地图河流从一个地块流向相邻地块：

- 当前小地图出口边界必须有河流地格
- 下游小地图入口边界必须有河流地格
- 入口/出口位置需要一致或在允许误差范围内
- 河床高度不应高于周围形成断流

## 缓存测试

需要验证：

- 第一次进入生成并写缓存
- 第二次进入读取缓存
- 缓存版本匹配时读取成功
- 缓存版本不兼容时忽略旧缓存
- 不兼容旧缓存不被删除

## 性能测试

首版目标：

- 单个默认尺寸小地图生成不明显卡顿
- 渲染只创建少量节点
- 不为每个地格创建独立 Node
