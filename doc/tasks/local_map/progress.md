# local_map 进度

## 当前状态

已完成基础小地图运行时代码：

- 双击大地图地块进入小地图。
- `CoreRoot` 负责大地图/小地图显示切换。
- `LocalMapService` 提供 `load_or_generate(tile)`。
- 首版使用 Godot 二进制 Variant 缓存，路径为 `user://local_maps/{seed}/v{version}/{tile_key}.bin`。
- `LocalMapRoot` 使用 `ImageTexture` 渲染 `sub_map_size x sub_map_size` 高度图。
- `LocalMapRoot` 根节点已改为 `CanvasLayer`，避免被大地图 `Camera2D` 平移/缩放后导致纹理不在屏幕内。
- 小地图支持右键拖动视图，以及按住 Ctrl 后滚轮缩放。
- 小地图支持左键选中地格、悬停预览和选中标记，左下角 UI 在小地图模式显示选中地格信息。
- `MapGeneratorPreview` 可以复用 `LocalMapGenerator` 直接生成选中地块的小地图预览；该开发工具入口不走小地图缓存。
- HUD 在小地图模式显示“返回大地图”按钮。
- 小地图边长由 `sub_map_size` 控制，默认 `64`，预览工具可调整。
- 小地图使用 `tile_col * sub_map_size + cell_x` / `tile_row * sub_map_size + cell_y` 全局采样坐标，保证小地图严格归属于对应大地图地块。
- 小地图 `water_flags` 与大地图海洋掩码保持一致，非海洋地块内部低洼不会直接显示为水域。
- 小地图高度生成已接入 `WorldSkeletonGenerator + WorldFunctionSampler`，逐地格采样连续世界高度。
- 小地图缓存版本已升级到 `v8`，避免读取地貌标签生成规则变更前的旧算法缓存。
- 河流已从基础入口/出口寻路升级为“完整全局河流折线裁剪 + 小地图地格级细化 + 动态宽度/深度切割”。
- 小地图河流宽度已改为按全局 `width_profile` 插值采样，保证相邻地块入口/出口宽度连续。
- 河流边界地格允许执行河床下切，用于保证相邻小地图的入口/出口连续。
- 小地图新增 `terrain_flags` bitmask，支持草地、森林、湿地、岩石、沙地、雪地多标签。
- `LocalCellState` 已作为临时地格查询视图接入。
- 小地图新增 `resource_instances`，由大地图 `resource_ids` 和地格地貌派生。
