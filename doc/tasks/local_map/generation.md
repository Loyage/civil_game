# local_map 生成设计计划

## 目标

小地图生成器需要在不提前生成所有地块内部结构的前提下，保证任意地块第一次进入时都能生成稳定、可复现、与邻居衔接合理的 `sub_map_size x sub_map_size` 小地图。

## 生成输入

- 世界种子 `world_seed`
- 大地图地块坐标 `tile_col/tile_row`
- 大地图地块状态 `TileState`
- 大地图相邻地块信息
- 大地图河流方向 `river_flow`
- 世界骨架中的完整河流折线 `WorldSkeleton.rivers[*].points`
- 大地图河流路径点 `river_path_points`，仅作为异常数据回退
- 大地图山脉脊线路径点 `ridge_path_points`

## 种子策略

当前实现使用：

```text
local_seed = hash(world_seed, tile_col, tile_row)
```

用途划分：

- 全局高度连续性：主要依赖全局地格坐标采样，不能只依赖单地块 seed
- 局部细节扰动：使用 `local_seed`
- 地貌派生随机性：使用 `local_seed` 加不同 salt

## 坐标策略

小地图内部坐标：

```text
cell_x: 0..sub_map_size - 1
cell_y: 0..sub_map_size - 1
```

全局地格坐标实际实现为大地图地块归属步长：

```text
global_cell_x = tile_col * sub_map_size + cell_x
global_cell_y = tile_row * sub_map_size + cell_y
```

原因是小地图必须严格采样所属大地图地块的全局坐标区间。旧版 `sub_map_size - 1` 步长会随着 tile 坐标累计偏移，导致小地图采样到相邻大地图地块，尤其会造成“大地图显示陆地，进入小地图后大面积为水”的不一致。

实现上，基础高度只使用全局高度场。大地图地块海拔、山脉、水体等宏观约束通过全局坐标和骨架掩码采样，避免小地图采样到相邻大地图地块的主体属性。

河流边界不再只标记不下切。为了让入口/出口真正连续，河流会优先使用完整全局河流折线裁剪当前地块内的河段，并允许在边界地格下切河床。这样相邻小地图会依据同一条全局折线得到共享边界上的河流位置。

## 高度范围

小地图每个地格高度是整数：

```text
-256..256
```

大地图地块与小地图地格当前都使用同一套 `-256..256` 高度语义，阈值、渲染和 UI 已按这一语义工作。

## 高度生成思路

当前实现分层：

1. 使用 `WorldSkeletonGenerator` 按当前地图配置和 seed 重建世界骨架。
2. 使用 `WorldFunctionSampler.sample_height(global_x, global_y)` 逐地格采样高度。
3. 全局坐标采用 `tile_col * sub_map_size + cell_x` / `tile_row * sub_map_size + cell_y`，保证小地图严格归属于对应大地图地块。
4. `water_flags` 只有在当前大地图地块属于 `skeleton.ocean_tiles` 且地格高度低于 `skeleton.sea_level` 时才标记为水域。
5. 山脉通过 `WorldFunctionSampler` 的山脉影响自然抬高，不额外沿 `ridge_path_points` 强化。
6. 河流约束根据大地图粗路径生成小地图地格级细化路径，并按动态宽度/深度压低河床高度。
7. 水体由大地图海洋掩码和海平面共同派生，不再只看 `height < 0`。
8. 坡度按周围 8 邻域最大高度差派生。
9. 地貌标签写入 `terrain_flags` bitmask，支持草地、森林、湿地、岩石、沙地、雪地多标签。
10. 森林、湿地、岩石、沙地、雪地会执行一次 `3 x 3` 邻域多数过滤，减少椒盐噪点。
11. 资源实例根据大地图 `resource_ids` 和小地图 `terrain_flags` 派生。

## 地貌标签生成

`terrain_flags` 当前是 `PackedInt32Array`，每个地格用 bitmask 表达多个标签：

- `grass`：普通非水陆地底层标签。
- `forest`：湿度高、非水体、低中海拔，并结合大地图 forest/rainforest biome 提高概率。
- `wetland`：靠近水体或河流，低海拔且湿度足够。
- `rock`：高坡度、高海拔或山脉影响明显。
- `sand`：低湿度且温度高。
- `snow`：极高海拔，或低温且较高海拔。

地貌派生只生成数据和基础颜色，不生成资源。

## 资源实例生成

资源生成在地貌标签之后运行：

- 动物：按资源定义生成 `1..3` 个静止个体，必须落在允许地貌上。
- 矿产：按资源定义生成 `2..5` 个相邻或近邻矿点，优先落在允许地貌，找不到时退化到任意非水陆地。
- 同类型资源不能占同一地格，不同类型资源允许重叠。
- 资源实例不写入小地图缓存，缓存命中后用同一 seed 重新派生。

## 河流生成

大地图指定河流粗路径，小地图内部路径按地格级重新细化：

- 入口和出口优先由 `WorldSkeleton.rivers` 中的完整全局河流折线决定。
- 生成器会用当前地块对应的世界坐标矩形裁剪河流折线，把裁剪结果转换为小地图内的控制点。
- 如果全局河流折线缺失，才回退到大地图 `river_path_points`、`river_flow` 和邻接关系。
- 小地图内部按相邻控制点分段执行 8 邻域寻路，最终拼接成完整河段。
- 寻路成本优先选择低处、缓坡和接近目标方向的地格。
- 寻路允许低成本上坡，用后续河流切割模拟河道切开局部洼地或低矮阻挡。
- 高海拔山体仍有额外成本，避免河流无代价穿越山脊。
- 河流宽度默认从 `3` 逐渐增长到最大 `12`，宽度以世界河流骨架的 `width_profile` 为准；小地图把细化路径地格投影回全局河流折线后插值读取宽度，保证相邻地块入口/出口宽度连续。
- 河床切割深度随河流宽度和下游距离增长，切割数据保存为 `river_carve_points`。
- 最外圈边界地格允许标记河流并改写高度，用于保证相邻地块入口/出口连续。
- 湖泊地块允许河流进入低洼水体后停止。

## 河流切割数据

`LocalMapState.river_carve_points` 保存细化后的河流切割轨迹。每个切割点记录：

- `cell_x`
- `cell_y`
- `global_x`
- `global_y`
- `width`
- `depth`

该数据不是完整世界级图层，只保存当前已生成小地图内的河流切割轨迹，后续可以用于调试、局部存档和更细的河流渲染。

## 水体规则

当前采用：

```text
tile in skeleton.ocean_tiles and height < skeleton.sea_level => water
```

非海洋大地图地块内部的低洼不会仅因为高度低于 `0` 被标记为水体。

## 大地图海拔关系

当前不立即强制大地图海拔等于小地图平均值。首版策略：

- 大地图按 `WorldFunctionSampler` 生成低分辨率摘要
- 小地图按同一 `WorldFunctionSampler` 对更密集的全局坐标采样
- 生成后计算 `average_height`
- 后续可以用小地图平均值校验大地图摘要，但当前不反向改写大地图地块
