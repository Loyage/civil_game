# local_map 生成设计计划

## 目标

小地图生成器需要在不提前生成所有地块内部结构的前提下，保证任意地块第一次进入时都能生成稳定、可复现、与邻居衔接合理的 `256 x 256` 小地图。

## 生成输入

- 世界种子 `world_seed`
- 大地图地块坐标 `tile_col/tile_row`
- 大地图地块状态 `TileState`
- 大地图相邻地块信息
- 大地图河流方向 `river_flow`
- 大地图河流路径点 `river_path_points`
- 大地图山脉脊线路径点 `ridge_path_points`

## 种子策略

首版规划使用：

```text
local_seed = hash(world_seed, tile_col, tile_row)
```

用途划分：

- 全局高度连续性：主要依赖全局地格坐标采样，不能只依赖单地块 seed
- 局部细节扰动：使用 `local_seed`
- 地貌派生随机性：使用 `local_seed` 加不同 salt

## 坐标策略

小地图内部坐标：

```text
cell_x: 0..255
cell_y: 0..255
```

全局地格坐标：

```text
global_cell_x = tile_col * 256 + cell_x
global_cell_y = tile_row * 256 + cell_y
```

边界连续性依赖全局地格坐标采样。相邻地块在共享边界附近采样同一个连续高度场，从算法层面避免边缘缝合。

## 高度范围

小地图每个地格高度是整数：

```text
-256..256
```

大地图地块海拔后续也改为同一范围的整数。当前大地图仍使用 `0..1` float，重构时需要从阈值、渲染和 UI 显示三处同步修改。

## 高度生成思路

首版生成分层：

1. 全局低频高度场：决定大陆、海岸和大地形趋势。
2. 大地图地块约束：让小地图平均高度接近当前大地图地块海拔对应的目标高度。
3. 局部高频扰动：生成细节起伏。
4. 山脉约束：如果大地图地块有山脉或山脉脊线，则沿 `ridge_path_points` 抬高高度。
5. 河流约束：如果大地图地块有河流，则根据入口/出口生成河道，并压低河床高度。

## 河流生成

大地图指定河流方向，小地图内部路径独立寻路：

- 入口和出口由大地图 `river_flow` 和邻接关系决定
- 如果存在上游邻居，则入口位置来自共享边界
- 出口位置根据 `river_flow` 映射到对应边界
- 小地图内部使用高度成本寻路，优先沿低处、缓坡通行
- 河床高度需要低于周围地格，保证连接处通畅
- 湖泊地块允许河流进入低洼水体后停止

## 水体规则

首版采用：

```text
height < 0 => water
```

后续可以引入 `sea_level` 配置，但首版默认海平面为 `0`。

## 大地图海拔关系

当前不立即强制大地图海拔等于小地图平均值。首版策略：

- 大地图先按现有逻辑生成宏观信息
- 小地图生成时尽量匹配对应地块的大地图海拔、山脉、河流和水体信息
- 生成后计算 `average_height`
- 后续重构时再用小地图平均值校验或调整大地图地块海拔
